Aplikasi Data Siswa

Versi Desktop 1.0.0 • SMK Nusantara Digital

✨ Fitur Aplikasi

  • 📋 Menampilkan daftar siswa dalam bentuk kartu
  • ➕ Menambah data siswa baru
  • 🔍 Mencari siswa berdasarkan nama / NISN
  • 👁️ Melihat detail informasi siswa
  • ✏️ Mengedit data siswa
  • 🗑️ Menghapus data siswa

🎨 Desain Visual

#5E1423 #7A1E2B #96303F #F6F0E4

Skema warna Burgundy & Cream Soft — nuansa elegan dan hangat. Font: Playfair Display (judul) & Poppins (isi). Layout desktop dengan sidebar navigasi di sisi kiri.

💻 Teknologi

Dibangun menggunakan HTML, CSS, dan JavaScript murni (vanilla) tanpa framework. Data tersimpan otomatis di browser melalui localStorage.

♻️ Pengaturan Data

Kembalikan seluruh data siswa ke kondisi awal (data contoh bawaan).

Dibuat untuk tugas perancangan UI/UX • Tema Burgundy & Cream 💝

🗑️

Hapus Data Siswa?

Data yang dihapus tidak dapat dikembalikan.
